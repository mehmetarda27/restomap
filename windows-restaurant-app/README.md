# RESTOMAP Restoran Windows

Canlı restoran panelini açan ve yeni sipariş fişlerini seçilen Windows yazıcısına sessizce gönderen masaüstü uygulamasıdır.

- Pencere kapatıldığında sistem tepsisinde çalışmaya devam eder.
- Windows açılışında otomatik başlar.
- Yeni siparişte Windows bildirimi ve ses verir.
- POS-SIFY, POS-80 ve yaygın termal yazıcı adlarını otomatik tanır; varsayılan yazıcı olmasını gerektirmez.
- Seçilen yazıcıyı bu bilgisayarda saklar ve sonraki açılışlarda aynı cihazı doğrudan kullanır.
- Sistem tepsisi menüsünden yazıcı seçilebilir, 58 mm/80 mm/A4 ölçüsü ayarlanabilir ve test fişi basılabilir.
- Yazıcı geçici olarak çevrim dışıysa fişi kuyrukta tutar ve 30 saniyede bir yeniden dener.
- Aynı paket kimliğini ikinci kez otomatik yazdırmaz.
- Oturum kalıcı uygulama profilinde saklanır.

## İlk kullanım

1. Uygulamayı açın. Bağlı termal yazıcı otomatik bulunur.
2. Windows sağ alt köşesindeki RESTOMAP simgesine sağ tıklayın.
3. Gerekirse **Yazıcı Seç** ile cihazı bir kez seçin ve **Kağıt** menüsünden 58 mm veya 80 mm belirleyin.
4. **Test Fişi Yazdır** ile bağlantıyı doğrulayın.

RESTOMAP dışındaki uygulamaların yazıcı ayarları değiştirilmez. Yazıcının Windows yazıcı listesinde görünmesi yeterlidir; varsayılan yazıcı yapılması gerekmez.
